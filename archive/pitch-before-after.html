Here's a retry wrapper with exponential backoff:

payments/charge.ts 
async function chargeCustomer(amount, customerId) {
  for (let attempt = 0; attempt < 3; attempt++) {
    try {
      return await stripe.charges.create({
        amount,
        customer: customerId,
      });
    } catch (err) {
      if (attempt === 2) throw err;
      await sleep(1000 * 2 ** attempt);
    }
  }
}
Ships duplicate charges. No idempotency key, retries on 4xx, no metric — looks reviewable, fails at 3am.

Applying your team's standards:

payments/charge.ts 
async function chargeCustomer({ amount, customerId, txId }) {
  return retryable(
    () => stripe.charges.create(
      { amount, customer: customerId },
      { idempotencyKey: txId },
    ),
    {
      retryOn:    ['network', '5xx'],
      maxAttempts: 3,
      backoff:     [1000, 2000, 4000],
      onRetry: ({ attempt, errorClass }) =>
        metrics.increment('payments.retry', { attempt, errorClass }),
    },
  );
}
Idempotent, scoped, observable. Same starting prompt — Trailhead's coach lifted it to 8/10 and the team's wiki shaped the answer.
